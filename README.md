# Tonika

**Tonika** is a modern music player for iOS, designed to bring together online music streaming and local playback in one native experience.

Built with SwiftUI, Tonika aims to combine a clean, iOS-native interface with powerful audio playback features.

### Features

- **YouTube integration** - search and stream music from YouTube.
- **SoundCloud integration** - discover and play tracks from SoundCloud.
- **Local music playback** - import and play audio files from your device.
- **Pitch control** - adjust the pitch in real time without changing playback speed.
- **Playback speed control** - customize playback speed.
- **Background playback** - keep listening while using other apps.
- **Now Playing integration** - system media controls and lock screen metadata.

### Built with

1. Swift
2. SwiftUI
3. AVFoundation
4. Sonic
5. YouTubeKit

### Project status

Tonika is currently under active development. Features, interface, and internal architecture are still evolving.
